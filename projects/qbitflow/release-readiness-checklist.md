# QBitFlow Release Readiness Checklist

## Critical Functionality

- [ ] Payment creation validated
- [ ] Checkout validated
- [ ] Supported networks validated
- [ ] Supported assets validated
- [ ] Payment confirmation validated
- [ ] Fee calculation validated
- [ ] Settlement validated

## Quality

- [ ] Critical defects addressed
- [ ] High-priority defects reviewed
- [ ] Regression testing completed where required
- [ ] Test evidence collected
- [ ] Known limitations documented

## Risk

- [ ] Outstanding financial risks reviewed
- [ ] Integration risks reviewed
- [ ] Environment limitations documented

## QA Principle

Release readiness should be based on evidence and accepted risk rather than an assumption that every possible scenario has been tested.
