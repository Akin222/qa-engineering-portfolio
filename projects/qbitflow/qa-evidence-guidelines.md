# QBitFlow QA Evidence Guidelines

## Purpose

Define what makes QA evidence useful and reproducible.

## Useful Evidence

- Screenshots
- Screen recordings
- API responses
- Console logs
- Network requests
- Transaction identifiers
- Test execution records
- Defect reproduction steps

## Evidence Quality

Evidence should:

- Support the reported observation.
- Be reproducible.
- Include relevant environment information.
- Avoid unnecessary sensitive information.

## Security

Never include:

- Private keys
- Seed phrases
- Passwords
- Authentication tokens
- Confidential production information

## QA Principle

Evidence should allow another tester or stakeholder to understand what was observed without relying solely on the tester's interpretation.
