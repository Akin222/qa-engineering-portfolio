# QBitFlow Console and Network Investigation

## Objective

Browser developer tools can provide supporting evidence when investigating unexpected application behavior.

## Console Checks

Look for:

- JavaScript errors
- Unhandled exceptions
- Failed resource loading
- Unexpected warnings
- Repeated errors

## Network Checks

Inspect:

- Request status codes
- Failed requests
- Response payloads
- Request timing
- Authentication-related failures
- API endpoint behavior

## QA Principle

Console and network evidence should support a reproducible defect rather than being treated as a defect by itself.

## Evidence

Relevant logs and responses should be captured without exposing credentials, tokens, private keys, or other sensitive information.
