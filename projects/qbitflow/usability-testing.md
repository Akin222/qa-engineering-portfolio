# QBitFlow Usability Testing

## Objective

Evaluate whether customers and merchants can understand and complete the payment workflow without unnecessary confusion.

## Customer Checks

- Payment instructions are understandable.
- Network and asset information is clear.
- Payment status is easy to interpret.
- Errors provide actionable information.
- Expired sessions clearly communicate the next step.

## Merchant Checks

- Payment status is understandable.
- Settlement information is easy to locate.
- Transaction information is presented consistently.
- Dashboard information supports basic payment reconciliation.

## QA Focus

Usability issues should be assessed based on their potential to cause user error, failed payments, confusion, or loss of trust.

## Execution Status

This document defines planned usability checks. Findings should only be documented after actual observation.
