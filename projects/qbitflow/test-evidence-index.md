# QBitFlow Test Evidence Index

## Purpose

This index provides a structured location for recording evidence collected during QA activities.

## Evidence Categories

### Functional Testing

- Checkout behavior
- Payment submission
- Payment status
- Settlement behavior

### Business Rules

- Platform fee calculation
- Payment expiry
- Supported networks
- Supported assets
- Merchant settlement amount

### Integration Testing

- API responses
- Payment processing
- Network confirmation
- Settlement integration
- Dashboard synchronization

### Defect Evidence

- Screenshots
- Reproduction steps
- Console logs
- Network logs
- API responses
- Transaction references

### Retesting Evidence

- Original defect reference
- Fix version
- Retest result
- Regression checks
- Final defect status

## Evidence Quality

Evidence should be:

- Relevant to the reported behavior
- Reproducible where possible
- Clearly associated with a test or defect
- Free from sensitive credentials or private information
- Sufficient to support the stated conclusion

## QA Principle

Evidence should support testing conclusions rather than simply documenting that a test was performed.
