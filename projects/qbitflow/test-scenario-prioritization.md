# QBitFlow Test Scenario Prioritization

## Objective

Prioritize test scenarios according to business impact, user impact, likelihood of failure, and financial risk.

## Priority 1 — Critical

- Successful payment and settlement
- Fee calculation
- Merchant wallet settlement
- Payment confirmation
- Incorrect payment amount

## Priority 2 — High

- Payment expiry
- Unsupported network
- Unsupported asset
- Payment status transitions
- Duplicate payment handling
- API integration failures

## Priority 3 — Medium

- Responsive behavior
- Cross-browser behavior
- Dashboard usability
- Accessibility checks

## QA Principle

Priority should guide testing effort rather than determine whether lower-priority functionality is ignored completely.
