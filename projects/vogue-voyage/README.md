# Vogue & Voyage — E-commerce QA Testing

## Project Overview

Vogue & Voyage is an e-commerce application tested as part of a practical software quality assurance engagement.

The testing focused on validating key customer-facing functionality, identifying defects, documenting findings, and verifying fixes through retesting.

## Testing Focus

- Functional testing
- UI testing
- Exploratory testing
- Smoke testing
- Regression testing
- Usability testing
- Responsive testing
- Error handling
- User journey validation

## QA Activities

The testing process included requirements review, test scope definition, test scenario design, execution, defect documentation, evidence collection, retesting, and final reporting.

Detailed testing documentation will be added to this project directory as the portfolio develops.
