# Boundary Value Testing

## Objective

Boundary value testing focuses on inputs and conditions at or near the limits accepted by a feature.

## Examples

Potential boundary conditions include:

- Minimum allowed quantity
- Maximum allowed quantity
- Empty values
- Minimum and maximum text lengths
- Zero values
- Very large values
- Minimum and maximum supported viewport sizes

## QA Approach

Where requirements define explicit limits, tests should validate values immediately below, at, and immediately above the accepted boundary where appropriate.

Boundary failures should be documented with the exact input and expected behavior.
