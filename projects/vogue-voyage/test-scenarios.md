# Test Scenarios

## Functional Test Scenarios

### Navigation
- Verify that the main navigation links open the correct destinations.
- Verify that navigation controls remain usable across supported screen sizes.

### Product Discovery
- Verify that users can browse available products.
- Verify that selecting a product opens the corresponding product details.
- Verify that product information is displayed consistently.

### Search
- Verify that valid search terms return relevant results.
- Verify that a search with no matching results provides appropriate feedback.
- Verify that clearing the search restores the expected product view.

### Shopping Cart
- Verify that a product can be added to the shopping cart.
- Verify that the cart reflects the correct selected product.
- Verify that product quantity changes are reflected correctly.
- Verify that removing a product updates the cart correctly.

### Error Handling
- Verify that invalid user actions receive appropriate feedback.
- Verify that failed operations do not leave the application in an inconsistent state.

### Responsive Behavior
- Verify that critical user journeys remain usable across desktop, tablet, and mobile screen sizes.

## Exploratory Testing

Exploratory testing is used to investigate areas where predefined scenarios may not fully represent real-world user behavior. Particular attention is given to navigation, search, product interaction, cart behavior, unexpected inputs, and inconsistent UI states.
