# Responsive Testing

## Objective

Responsive testing validates whether the application remains usable and visually coherent across different viewport sizes.

## Areas Checked

- Navigation
- Page layout
- Product presentation
- Images
- Buttons and controls
- Search
- Shopping cart
- Text readability
- Horizontal scrolling
- Touch-oriented interactions

## Risk Areas

Particular attention should be given to elements that can become difficult to use when screen width changes, including navigation controls, buttons, forms, product layouts, and cart interactions.
