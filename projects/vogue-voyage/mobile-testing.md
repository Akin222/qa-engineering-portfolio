# Mobile Testing

## Objective

Mobile testing evaluates whether critical user journeys remain functional and usable on mobile devices and smaller viewports.

## Coverage

- Navigation
- Product discovery
- Product details
- Search
- Cart interactions
- Touch interactions
- Forms and inputs
- Responsive layouts
- Error handling

## Key Risks

Particular attention should be given to controls that may become difficult to access or interact with on smaller screens, including navigation elements, buttons, forms, and cart controls.
