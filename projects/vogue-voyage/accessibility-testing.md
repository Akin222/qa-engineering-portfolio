# Accessibility Testing

## Objective

Accessibility testing evaluates whether important functionality can be used by people with different interaction needs and abilities.

## Areas to Consider

- Keyboard navigation
- Focus visibility
- Form labels
- Button names
- Image alternative text
- Color contrast
- Heading structure
- Error messaging
- Interactive element accessibility

## QA Perspective

Accessibility should be considered alongside functional and usability testing because an application can be technically functional while still presenting significant barriers to some users.
