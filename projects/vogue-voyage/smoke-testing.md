# Smoke Testing

## Objective

Smoke testing provides a quick assessment of whether the application is stable enough for deeper testing.

## Critical Checks

- Application loads successfully
- Main navigation is accessible
- Product pages can be opened
- Search is available
- Products can be interacted with
- Shopping cart is accessible
- Critical UI controls respond as expected

## Decision

If a critical function prevents meaningful testing from continuing, the issue should be documented and communicated before proceeding with extensive test execution.
