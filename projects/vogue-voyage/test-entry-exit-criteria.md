# Test Entry and Exit Criteria

## Entry Criteria

Testing can begin when the required conditions are available, including:

- Testable application build
- Defined testing scope
- Available test environment
- Relevant requirements or expected behavior
- Required test data
- Access to necessary functionality

## Exit Criteria

Testing may be considered complete when:

- Planned critical scenarios have been executed
- Significant defects have been documented
- Required retesting has been completed
- Regression coverage has been performed where appropriate
- Outstanding risks have been communicated
- Test results have been documented

## Important Note

Exit criteria should be evaluated against the agreed testing scope and risk level rather than assuming that all possible defects have been discovered.
