# Negative Testing

## Objective

Negative testing validates how the application behaves when users provide invalid, unexpected, incomplete, or unsupported inputs.

## Scenarios

- Empty search input
- Invalid search values
- Unexpected characters
- Missing required information
- Invalid quantities
- Repeated rapid interactions
- Unsupported actions
- Unexpected navigation states

## Expected Behavior

The application should respond predictably, provide appropriate feedback where necessary, and avoid entering an inconsistent state.

## QA Value

Negative testing helps identify weaknesses that may not appear when testing only expected user behavior.
