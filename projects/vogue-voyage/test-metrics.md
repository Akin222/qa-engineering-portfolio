# Test Metrics

## Purpose

Test metrics provide a concise view of testing progress, coverage, and defect status.

## Core Metrics

### Test Execution

Track:

- Total scenarios
- Executed scenarios
- Passed scenarios
- Failed scenarios
- Blocked scenarios
- Not executed scenarios

### Defect Metrics

Track:

- Total defects
- Critical defects
- High-severity defects
- Medium-severity defects
- Low-severity defects
- Open defects
- Fixed defects
- Reopened defects
- Closed defects

### Coverage

Coverage can be assessed by comparing the functionality planned for testing with the functionality actually evaluated.

## Interpretation

Metrics should provide context rather than being treated as proof of software quality by themselves.

A high pass rate does not necessarily indicate high quality if important functionality has not been adequately tested.

## Reporting

Metrics should be interpreted alongside test scope, risk, known limitations, defect severity, and outstanding quality concerns.
