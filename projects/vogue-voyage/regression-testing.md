# Regression Testing

## Objective

Regression testing verifies that changes or fixes have not negatively affected existing functionality.

## Regression Areas

Regression checks should prioritize:

- Previously reported defects
- Critical user journeys
- Related functionality affected by a change
- Core navigation
- Product interaction
- Search
- Shopping cart
- Responsive behavior

## Risk-Based Regression

Regression scope should be influenced by the nature and risk of the change rather than treating every release as requiring identical coverage.

Critical functionality receives priority when testing time is limited.
