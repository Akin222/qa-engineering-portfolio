# Network Validation

## Objective

Network validation helps identify failures involving requests between the application and backend services.

## Areas to Inspect

- Request URL
- HTTP method
- Status code
- Request payload
- Response payload
- Request timing
- Failed requests
- Missing resources

## QA Value

Network observations can provide additional context when functionality fails, particularly when the UI does not clearly communicate the underlying problem.

Relevant network evidence should be included in defect reports when it helps developers reproduce or diagnose the issue.
